# 개인·그룹 알림 서비스 — UI 디자인 명세

이 문서는 확정된 디자인 시안(모바일 10개 화면)을 구현용으로 옮긴 것이다. 기능 요구사항은 PRD를 따르고, 화면 구성·스타일·문구는 이 문서를 따른다. PRD와 이 문서가 다를 때는 "5. PRD와 달라진 점"의 내용이 우선한다.

- 기준 화면: 모바일 390 × 844 px (세로)
- 언어: 한국어, 안내 문구는 "~해요" 말투
- 기술 스택은 이 문서에서 정하지 않는다. 값은 CSS px 기준이다.

## 1. 디자인 토큰

### 색상

| 토큰 | 값 | 용도 |
|---|---|---|
| `bg` | `#F3F5F7` | 화면 바탕, 입력란·비선택 칩 채움 |
| `surface` | `#FFFFFF` | 카드, 탭 바, 로그인·초대 화면 바탕 |
| `text` | `#17202B` | 기본 글자 |
| `text-sub` | `#5B6675` | 보조 글자, 비선택 탭 |
| `text-mid` | `#46505E` | 안내 상자 글자, '미확인' 배지 글자 |
| `accent` | `#1F5FE0` | 주요 버튼, 선택 상태, '확인' 배지, 강조 숫자 |
| `accent-soft` | `#E6ECF5` | 보조 버튼 바탕, 아바타 바탕, 안내 상자 바탕 |
| `line` | `#E9ECF0` | 탭 바 위 경계선, 전환 버튼 트랙, '미확인' 배지 바탕, 진행 막대 트랙 |
| `neutral-btn` | `#E1E5EA` | 중립 버튼(그룹 탈퇴) 바탕 |
| `toggle-off` | `#8A93A0` | 꺼진 토글 트랙 |

포인트 색은 `accent` 하나만 쓴다. '확인'과 '미확인'은 색뿐 아니라 명도로도 구분된다(진한 파랑 채움 vs 연한 회색 채움).

### 글자

- 서체: `'Noto Sans KR', system-ui, sans-serif` (굵기 400 / 500 / 700)
- 기본: 15px, 줄 간격 1.45, 자간 -0.01em

| 용도 | 크기 / 굵기 |
|---|---|
| 로그인 헤드라인 | 30px / 700, 줄 간격 1.35, 자간 -0.03em |
| 초대 헤드라인 | 28px / 700, 줄 간격 1.35, 자간 -0.03em |
| 화면 큰 제목 | 24px / 700, 자간 -0.03em |
| 뒤로가기 헤더 제목 | 18px / 700 |
| 알림 카드 제목 | 17px / 700 (확인 완료 카드는 500, `text-mid`) |
| 카드 섹션 제목, 목록 주요 이름 | 16px / 700 |
| 본문, 목록 이름 | 15px / 500 |
| 보조 설명, 메타 정보, 탭 라벨 | 13px / 400 |
| 배지 | 12px / 700 |
| 주요 버튼 라벨 | 17px / 700 |

### 모서리·간격

| 항목 | 값 |
|---|---|
| 카드 모서리 | 20px |
| 주요 버튼 모서리 | 16px |
| 입력란·보조 버튼·칩·안내 상자 모서리 | 14px |
| 전환 버튼 선택 조각 모서리 | 10px |
| 배지 모서리 | 8px |
| 화면 좌우 여백 | 16px (큰 제목 헤더는 20px) |
| 카드 안쪽 여백 | 20px |
| 카드 사이 간격 | 12px |
| 터치 영역 최소 높이 | 44px |

카드에는 테두리와 그림자를 쓰지 않는다. 그림자는 전환 버튼의 선택 조각에만 쓴다: `0 1px 3px rgba(23, 32, 43, 0.12)`.

## 2. 공통 컴포넌트

| 뒤로가기 헤더 | 높이 56px. 왼쪽 44×44 아이콘 버튼(뒤로 `<` 또는 닫기 `×`), 제목 18px/700. 작성 흐름에서는 오른쪽에 단계 표시 `1 / 2` (13px/700, `accent`) |

| 요일 칩 | 7칸 균등 격자, 간격 6px, 높이 44px, 원형. 선택 규칙은 선택 칩과 동일 |
| 토글 | 트랙 52×32px, 손잡이 26px 흰 원. 켬: `accent`, 끔: `toggle-off`. 터치 영역 52×44px |
| 체크박스·라디오 | 22×22px, 선택 색 `accent`, 행의 오른쪽 끝에 배치 |
| 배지 '확인' | `accent` 바탕, 흰 글자, 12px/700, 여백 3px 10px, 모서리 8px |
| 배지 '미확인' | `line` 바탕, `text-mid` 글자, 그 외 동일 |
| 아바타 | 40px 원, `accent-soft` 바탕, `accent` 글자(닉네임 첫 글자, 14px/700). 그룹은 44px, 모서리 16px 사각 |
| 안내 상자 | `accent-soft` 바탕, 모서리 14px, 여백 14px 16px, 13px `text-mid` |
| 목록 행 | 최소 높이 60~64px, 구분선 없음, 아바타 + 이름(+ 보조 정보 13px) |
| 하단 탭 바 | 높이 60px, `surface` 바탕, 위 경계선 1px `line`. 탭 4개 균등: 받은 알림 / 보낸 알림 / 친구 / 그룹. 글자만 표시(13px). 현재 탭: `accent`, 700. 나머지: `text-sub` |

아이콘은 선형 아이콘만 쓴다(선 굵기 1.8~2.2px, 둥근 끝). 사용처: 뒤로, 닫기, 오른쪽 꺾쇠, 체크, 로그인 화면의 종.

## 4. 화면별 명세

### 01 로그인
- 바탕 `surface`. 여백 120px 24px 40px. 위쪽 묶음과 아래쪽 묶음을 위아래 끝으로 배치.
- 위: 72px 앱 아이콘(모서리 24px, `accent` 바탕, 흰 종 아이콘) → 헤드라인 "알림을 보내고 / 누가 확인했는지 / 한눈에 보세요"(3줄) → 설명 "개인이나 그룹에 보내고, 회차별로 확인 현황을 볼 수 있어요." (16px, `text-sub`)
- 아래: "Google 계정으로 계속하기" 버튼(높이 56px, `bg` 바탕, 16px/700, 왼쪽에 24px 흰 원 안 'G') → "처음 로그인하면 계정이 자동으로 만들어져요." (13px, 가운데 정렬)

### 02 친구
- 큰 제목 "친구"
- 카드 1 "이메일로 친구 추가": 이메일 입력란(예시 문구 `friend@example.com`) + '추가' 버튼(`accent`). 설명 "가입된 사용자의 이메일 주소를 입력하세요."
- 카드 2 "내 친구 N"(N은 `accent`): 친구 행(아바타, 닉네임, 이메일 13px)
- 안내 상자: "개인 발송은 친구 목록에 있는 사용자에게만 보낼 수 있어요."
- 하단 주요 버튼 "새 알림 작성" + 탭 바(친구)

### 03 그룹 목록
- 큰 제목 "그룹"
- 카드 1 "새 그룹 만들기": 그룹 이름 입력란 + '만들기' 버튼. 설명 "만든 뒤 초대 링크로 구성원을 초대해요."
- 카드 2 "내가 속한 그룹 N": 그룹 행(사각 아바타, 그룹명 16px/700, "구성원 N명 · 최근 발송 날짜" 13px, 오른쪽 꺾쇠). 행 최소 높이 72px.
- 안내 상자: "내가 속한 그룹만 보여요. 속하지 않은 그룹에는 발송하거나 기록을 볼 수 없어요."
- 하단 주요 버튼 "새 알림 작성" + 탭 바(그룹)

### 04 그룹 상세 · 구성원
- 뒤로가기 헤더, 제목은 그룹명
- 카드 1 "초대 링크": 링크 표시 상자(`bg` 채움, 한 줄, 넘치면 말줄임) + '복사' 보조 버튼. 설명 "친구가 아니어도 링크로 가입할 수 있어요. 초대를 수락한 시점부터 구성원이 돼요."
- 카드 2 "내 이메일 공개" + 토글. 설명 "끄면 구성원 목록에 닉네임만 보여요."
- 카드 3 "구성원 N": 구성원 행. 닉네임은 항상 표시, 이메일은 그 사람이 공개를 켠 동안에만 닉네임 아래 13px로 표시. 본인은 "닉네임 (나)".
- 하단: '그룹 탈퇴'(중립, 비율 1) + '이 그룹에 알림 보내기'(주요, 비율 2), 간격 8px

### 05 초대 수락
- 바탕 `surface`, 헤더 없음. 여백 88px 24px 24px, 요소 간격 24px, 왼쪽 정렬.
- 72px 그룹 아이콘(모서리 24px, `accent-soft`) → 헤드라인 "{그룹명}에 / 초대받았어요" → "{초대한 사람} 님이 초대했어요 · 구성원 N명" (16px, `text-sub`)
- 회색 상자(`bg`, 모서리 20px) "수락하면": 지금부터 그룹 구성원이 돼요 / 이 그룹에 알림을 보내고 받을 수 있어요 / 가입 이후 발송된 회차의 알림과 응답 현황만 볼 수 있어요 / 구성원 목록에는 닉네임만 보여요. 이메일 공개는 직접 선택해요.
- 설명: "수락 전에는 그룹에 포함되지 않으며, 발송하거나 응답 현황을 볼 수 없어요."
- 하단: '나중에'(`bg` 바탕, 비율 1) + '초대 수락'(주요, 비율 2)

### 06 알림 작성 · 개인 발송
- 닫기 헤더 "새 알림", 단계 `1 / 2`
- 카드 1 "어떤 알림을 보낼까요?": 여러 줄 입력란 하나(예시 문구 "예: 주간 회의 자료 제출"). 설명 "제목 없이 한 문장으로 보내요." 제목과 내용을 나누는 입력란은 두지 않는다.
- 카드 2 "누구에게 보낼까요?": 전환 버튼 [개인 | 그룹], '개인' 선택. 설명 "개인과 그룹은 함께 지정할 수 없어요."
- 카드 3 "받는 친구 N"(N = 선택 수): 친구 목록 체크박스 행(높이 48px). 설명 "친구 목록에 있는 사용자만 선택할 수 있어요. 한 명 이상 골라 주세요."
- 하단 주요 버튼 "다음"

### 07 알림 작성 · 그룹 발송
- 06과 같은 구조. 전환 버튼은 '그룹' 선택.
- 카드 3 "받는 그룹 (한 그룹만)": 내가 속한 그룹 라디오 행(그룹명, "구성원 N명", 높이 56px)
- 카드 3 안 아래쪽 안내 상자: "수신 예정 N명 · 이름, 이름, 이름"(`accent`, 700) / "발송 시점의 구성원 중 나를 제외한 전원이 받아요. 반복 알림은 회차마다 다시 정해져요."
- 하단 주요 버튼 "다음"

### 08 발송 일정
- 뒤로가기 헤더 "언제 보낼까요?", 단계 `2 / 2`
- 카드 1 "발송 유형": 전환 버튼 [일회성 | 반복]
- 카드 2 "반복 주기": 선택 칩 [매일 | 매주 | 매월] → "요일" 요일 칩 7개(월~일) → "발송 시각" 입력란(예시 문구 "오전 9:00")
- 카드 3 "주말 제외" + 토글. 설명 "토·일 회차는 다음 평일에 보내요." 켜면 안내 상자 표시: "매주 토요일 회차는 다음 월요일에 보내요." / "다음 발송 11월 16일(월) 오전 9:00"(`accent`, 700)
- 하단 주요 버튼 "발송 예약하기"
- 시안은 '반복 · 매주 · 토요일 · 주말 제외 켬' 상태다. 일회성, 매일, 매월 선택 시의 입력 구성은 시안에 없다(6장 참고).

### 09 받은 알림 · 확인
- 큰 제목 "받은 알림", 그 아래 "아직 확인하지 않은 알림 N건"(N건은 `accent`, 700). 헤더 오른쪽에 '새 알림' 알약 버튼(높이 44px, 모서리 22px, `accent` 바탕, 14px/700).
- 알림 상세 화면은 없다. 확인과 응답 현황 이동을 모두 카드에서 한다.
- 알림 카드(회차마다 1장, 요소 간격 10px):
  - 윗줄: 알림 문구(17px/700) + 오른쪽 상태 배지
  - 메타(13px, `text-sub`): 그룹 발송 "{그룹명} · {발신자} · {주기} {N}회차 · {날짜 시각}", 개인 발송 "개인 · {발신자} · {주기} · {날짜 시각}"
  - 버튼 줄(높이 48px, 간격 8px):

| 카드 상태 | 왼쪽 | 오른쪽 |
|---|---|---|
| 그룹 발송, 미확인 | '확인' 주요 버튼(체크 아이콘 + 글자) | '응답 현황' 보조 버튼 |
| 그룹 발송, 확인 완료 | 비활성 "{날짜 시각} 확인함"(`bg` 바탕, `text-sub`, 13px) | '응답 현황' 보조 버튼 |
| 개인 발송, 미확인 | '확인' 주요 버튼(한 줄 전체 너비) | 없음 |

  - 개인 발송 카드에는 버튼 아래 "개인 알림은 내 확인 여부만 볼 수 있어요." (13px)
  - 확인 완료 카드의 알림 문구는 500, `text-mid`
- 안내 상자: "‘확인’ 버튼을 눌러야 확인으로 바뀌어요. 반복 알림은 회차마다 따로 보여요."
- 탭 바(받은 알림)

### 10 응답 현황
- 헤더: 윗줄 "응답 현황 · {그룹명} · {발신자} · {주기}"(13px, `text-sub`), 아랫줄 알림 문구(24px/700)
- 카드 1 "발송 회차": 회차 버튼 가로 나열(높이 60px, 모서리 14px, 13px, 두 줄 "N회차 날짜" / "확인 x/y")
  - 선택: `accent` 바탕, 흰 글자, 700
  - 비선택: `accent-soft` 바탕, `text` 글자
  - 조회 불가(가입 전 회차): 비활성, `bg` 바탕, `text-sub` 글자, 둘째 줄 "조회 불가"
  - 설명: "가입 전에 발송된 회차는 볼 수 없어요."
- 카드 2: "N명 중 M명이 확인했어요"(M명은 `accent`) + 오른쪽 "N회차 · 날짜"(13px) → 진행 막대(높이 8px, 트랙 `line`, 채움 `accent`) → 수신자 행(아바타, 닉네임, 확인 시각 13px, 오른쪽 상태 배지). 본인은 "닉네임 (나)".
- 안내 상자: "개인 발송은 발신자에게 모든 수신자가, 수신자에게는 본인만 보여요. 그룹을 탈퇴하면 이 화면은 ‘조회 권한 없음’으로 바뀌어요."
- 탭 바(보낸 알림)

## 5. PRD와 달라진 점

| 항목 | PRD | 확정된 디자인 |
|---|---|---|
| 확인 위치 | 알림을 열고 '확인' 버튼을 누름 (5장) | 알림 상세 화면 없음. 받은 알림 목록의 카드에서 바로 '확인' |
| 알림 구성 | 명시 없음 | 제목과 내용을 나누지 않고 한 문장으로 작성·표시 |

그 밖의 규칙은 PRD 그대로다. 화면에 반영된 핵심 규칙:

- 앱 진입이나 목록 열람만으로는 '미확인' 유지. '확인' 버튼을 눌러야 해당 회차의 상태가 바뀐다.
- 반복 알림은 회차마다 '미확인'에서 새로 시작하고, 받은 알림에 회차별 카드로 표시된다.
- 개인 발송: 친구 목록에서 1명 이상. 수신자는 본인 확인 여부만 볼 수 있어 '응답 현황' 버튼이 없다.
- 그룹 발송: 내가 속한 그룹 중 1개. 수신자는 발송 시점 구성원 중 발신자를 제외한 전원.
- 개인과 그룹은 한 알림에 함께 지정할 수 없다.
- 그룹 기록은 가입 이후 회차만 조회 가능. 탈퇴 즉시 그 그룹의 모든 기록을 볼 수 없다.
- 구성원 목록은 닉네임 기본, 이메일은 본인이 공개를 켠 동안에만 표시.
- 주말 제외를 켜면 토·일 회차는 다음 평일로 옮겨 발송.

## 6. 시안에 없는 부분

구현 전에 결정이 필요하다. 임의로 확정하지 말고 요구사항 단계에서 확인한다.

- 이메일 공개 설정의 범위: 시안은 그룹 상세 화면의 토글이다. 그룹별 설정인지 계정 전체 설정인지 PRD에 없다.
- 보낸 알림 목록: '보낸 알림' 탭은 시안에서 응답 현황 화면 하나로 바로 연결된다. 보낸 알림이 여러 개일 때의 목록 화면이 없다.
- 개인 발송의 응답 현황: 발신자가 보는 화면은 10번과 같은 구조로 가정했고, 별도 시안은 없다.
- '조회 권한 없음' 상태(탈퇴 후, 그룹 외부 사용자)의 화면
- 발송 일정에서 일회성(날짜 선택), 매일, 매월(날짜 선택) 선택 시의 입력 구성
- 빈 상태(친구·그룹·알림이 없을 때), 불러오는 중, 오류, 입력 검증 실패 상태
- 친구 추가 실패(미가입 이메일), 그룹 탈퇴 확인, 링크 복사 완료 등의 피드백
- 로그아웃과 닉네임 설정 화면
